# Test report

Every row was produced by running the check against the live app: both servers started on a copy of the **pre-feature database** (the oldest backup, 12 tables, 49 bookings, migrated on start), seeded with rooms and photos, peak and sold-out dates, promo codes, sevas, a festival and staff users; mock SMS, WhatsApp, email, Sheets and Razorpay; real OTP. Run it yourself: `python tools/audit_run.py` (needs Playwright with Edge or Chromium; opencv, pymupdf and axe-core are optional and a missing one makes its check BLOCKED, never PASS).

**Final result: 60 PASS, 9 FAIL→FIXED (failed on first run, fixed, now passing), 1 BLOCKED, 0 FAIL.**

Unit and regression suites (all green on the final run): test_mantralayam_rooms, test_mantralayam_staff, test_mantralayam_features, test_i18n, test_pay_notify, test_staff_desk, test_reports, test_extras, test_audit_fixes.

## Blocked, and what is needed to run them yourself
- **External links** (OpenStreetMap, Google Fonts, Razorpay Checkout script, wa.me): not fetched (no internet assumed). Open each once from a connected machine.
- **Live Razorpay**: the mock follows the same interface; not run against Razorpay. Supply `rzp_test_` key id and secret, a webhook secret, and register the webhook URL; then repeat the Payments rows.
- **Live SMS, WhatsApp and email gateways**: only the mock providers were run. Supply `SMS_HTTP_URL`/`SMS_HTTP_TOKEN`, `WHATSAPP_*`, SMTP settings.
- **Live Google Sheets**: only the mock and the fallback were run. Supply `GOOGLE_SERVICE_ACCOUNT_JSON`, `GOOGLE_SHEETS_ID` (sheet shared with the service account) and `cryptography` or `openssl` on the server.
- **Real Caddy/nginx/systemd validators** were not installed here; only structural checks ran. Run `caddy validate`, `nginx -t`, `systemd-analyze verify` on the server.
- **Installing the app** was checked with Chromium's installability test (the only error is Playwright's incognito mode). A real install on a phone was not done.
- **Indian-script fonts**: rendered correctly here (Telugu screenshot inspected; Kannada, Tamil, Hindi rendered without raw keys but were not inspected visually). Fonts come from Google Fonts, which was unreachable here, so these used system fonts: confirm on a phone.
- **Lighthouse** was not run; axe-core (WCAG 2 A/AA) was.
- Translations in Telugu, Kannada, Tamil and Hindi are machine-drafted and unreviewed; many strings are still `TODO` (shown in English).

## Not covered (said honestly)
- Early-departure refunds (check-out before the booked date) do not exist; "partway" was tested as cancelling one room of a multi-room booking.
- The mock SMS provider prints OTP codes to the server console by design (development only). The real provider was shown not to log a code, even when sending fails.
